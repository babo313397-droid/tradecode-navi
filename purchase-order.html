📝 발주서 작성

제품 마스터를 기준으로 여러 PO의 동일 제품을 한 줄로 합산해 발주서를 만듭니다.
1제품 목록 관리
기존 제품리스트 엑셀 · 쿠팡 PO 제품 엑셀 · 제품목록 캡처 이미지를 여기에 끌어놓으세요기존 제품리스트 엑셀은 전체 업데이트용 · 쿠팡 PO 제품 엑셀은 기존 제품을 제외하고 신규 제품만 미리보기 후 추가 · 캡처 이미지는 반자동 신규 등록 방식입니다.
등록된 제품 목록을 불러오는 중입니다…
쿠팡 PO 제품 엑셀 · 신규 제품 미리보기
신규만 추가: 현재 로그인 계정의 제품목록과 상품번호 우선 + 바코드 보조로 비교합니다. 이미 등록된 제품은 자동으로 저장 대상에서 제외합니다. 캐비티는 상품명의 “4개 1세트 / 2p / 3개입 / 2EA / 4매” 같은 표현에서 우선 제안하며, 제품 사진도 함께 보여주므로 저장 전 직접 확인하고 수정할 수 있습니다.
계정별 영구 저장: 제품 목록과 사진은 현재 로그인 계정 전용 Render Persistent Disk 저장소에 보관됩니다. 기존 관리자 계정의 현재 제품목록은 그대로 유지되고, 다른 계정에서는 서로의 제품목록이 보이지 않습니다.
제품목록 캡처 이미지 반자동 신규 제품 추가
제품목록 화면 캡처(PNG/JPG/WEBP)를 여기에 끌어놓으세요여러 장 가능 · 브라우저에서 상품번호와 바코드만 자동 인식합니다. 상품명은 아래 미리보기의 원본 행을 보면서 직접 입력하고, 입력한 상품명에서 캐비티를 자동 제안합니다.
캡처 이미지를 올리면 상품번호/바코드만 자동 인식합니다.
무료 반자동 방식: 별도 유료 AI API를 사용하지 않습니다. 캡처에서 제품 사진 + 상품번호 + 바코드만 자동 인식하고, 상품명은 원본 행 미리보기를 보며 직접 입력합니다. 상품명을 입력한 뒤 다른 칸을 클릭하면 “2개 1세트 / 3개입” 같은 표현에서 캐비티를 자동 제안합니다. 인식이 틀린 상품번호·바코드도 저장 전에 직접 수정할 수 있습니다.

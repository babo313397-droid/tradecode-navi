📝 발주서 작성

제품 마스터를 기준으로 여러 PO의 동일 제품을 한 줄로 합산해 발주서를 만듭니다.
1제품 목록 관리
기존 제품리스트 엑셀 또는 제품목록 캡처 이미지를 여기에 끌어놓으세요엑셀은 전체 등록/업데이트용 · 캡처 이미지는 제품 사진과 상품번호/바코드만 자동 인식하고, 상품명은 사람이 확인해 입력하는 반자동 신규 등록 방식입니다.
등록된 제품 목록을 불러오는 중입니다…
영구 저장: 제품 목록과 사진은 코드 폴더가 아니라 Render Persistent Disk의 /var/data/tradecode/purchase-order/product-master에 저장됩니다. 사이트 업데이트나 재배포로 제품 목록이 초기화되지 않습니다.
제품목록 캡처 이미지 반자동 신규 제품 추가
제품목록 화면 캡처(PNG/JPG/WEBP)를 여기에 끌어놓으세요여러 장 가능 · 브라우저에서 상품번호와 바코드만 자동 인식합니다. 상품명은 아래 미리보기의 원본 행을 보면서 직접 입력하고, 입력한 상품명에서 캐비티를 자동 제안합니다.
캡처 이미지를 올리면 상품번호/바코드만 자동 인식합니다.
무료 반자동 방식: 별도 유료 AI API를 사용하지 않습니다. 캡처에서 제품 사진 + 상품번호 + 바코드만 자동 인식하고, 상품명은 원본 행 미리보기를 보며 직접 입력합니다. 상품명을 입력한 뒤 다른 칸을 클릭하면 “2개 1세트 / 3개입” 같은 표현에서 캐비티를 자동 제안합니다. 인식이 틀린 상품번호·바코드도 저장 전에 직접 수정할 수 있습니다.
캐비티 자동 분석 · 상품명에서 “2개 1세트 / 3개입 / 4매 / 2P / 2EA” 같은 수량표현을 찾아 캐비티를 제안합니다.
분석 전 · 자동 분석은 저장하지 않으며, 결과를 확인한 뒤 확정 저장합니다.

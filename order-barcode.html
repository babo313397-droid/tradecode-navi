📦 발주 바코드 출력

발주현황 엑셀을 불러오면 공용 보관함의 라벨과 자동 매칭하고, 50×30 / 50×60 용지를 따로 일괄 출력하거나 상품별로 원하는 수량만 출력할 수 있습니다.
프린터 출력 방식
QZ Tray 설치 후 Xprinter와 직접 통신합니다. QZ Tray 설치
발주서에서 상품번호 / 바코드 / 상품명 / 발주수량 헤더를 자동으로 찾습니다. 공용 라벨 매칭은 바코드 우선 → 상품번호 순서입니다.
① 연속 출력은 라벨 1장씩 이어서 출력합니다. ② 다열 라벨 용지는 A4 등 한 장의 용지에 여러 라벨을 가로·세로로 배치합니다. PDF 버튼은 파일 저장, 프린터 버튼은 브라우저 인쇄창을 바로 엽니다.
엑셀의 발주수량 셀이 노란색/빨간색이면 웹 표에도 같은 의미의 색으로 표시합니다. 현재 출력매수는 같은 발주 파일을 다시 불러와도 이 브라우저에서 기억하며, 발주수량 이상 출력되면 초록색으로 표시합니다.

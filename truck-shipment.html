🚛 트럭쉽먼트 자동입력

선적건의 팔레트별 상품번호·수량을 TruckShipment와 자동 매칭합니다.
원본의 확정수량(G열)과 팔레트 생성가능 수량(H열)은 변경하지 않습니다.

✓ I/J열만 자동 입력 · 분할 시 새 행 생성
파일 2개를 선택해 주세요
자동입력 기준 · 선적건 팔레트 1번부터 마지막 팔레트까지 순서대로 처리합니다. 동일 SKU가 여러 PO에 있으면 TruckShipment 행 순서대로 H열 가능수량 범위에서 배분합니다. 한 TruckShipment 행이 두 팔레트에 나뉘면 원본 행은 그대로 두고 필요한 새 행을 맨 아래에 복제합니다. 새 행도 기존 테두리·가운데 정렬 서식을 그대로 복사하며 I/J열은 기존 노란색 서식을 유지합니다.
두 파일을 선택하면 자동으로 분석을 시작합니다.

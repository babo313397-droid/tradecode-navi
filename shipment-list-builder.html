1. 원본 선적 엑셀 불러오기
원본 선적 엑셀을 여기에 끌어놓으세요또는 아래 ‘파일 선택’을 눌러 .xlsx / .xlsm 파일을 선택하세요.
정리 전 원본 파일을 불러와 주세요.
정리 기준: 같은 업체 + 같은 센터 + 같은 상품번호/바코드인 행의 발주수량(E열)을 합산합니다. 같은 상품이라도 센터가 다르면 서로 합치지 않습니다. 센터 셀 색상은 업체+센터별로 자동 지정됩니다.
기존 파일은 변경하지 않습니다. 원본 엑셀은 읽기만 하고, 정리 결과는 새 Excel 파일로 다운로드합니다. 쿠팡 입고 작업·바코드 라벨·서버 저장 데이터에도 영향을 주지 않습니다.

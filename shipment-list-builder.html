선적 리스트 작성

동일 상품 · 동일 센터 발주수량 자동 합산
1. 원본 선적 엑셀 불러오기
원본 선적 엑셀 1~3개를 여기에 끌어놓으세요코리아원 · 봄날애 · 차통익스프레스 파일을 한 번에 여러 개 올리거나, 한 개씩 추가로 올려도 됩니다.
정리 전 원본 파일을 불러와 주세요.
정리 기준: 여러 원본 파일을 하나로 합친 뒤, 같은 업체 + 같은 센터 + 같은 상품번호/바코드인 행의 발주수량(E열)을 합산합니다. 같은 상품이라도 센터가 다르면 서로 합치지 않습니다. 센터 셀 색상은 업체+센터별로 자동 지정됩니다.
기존 파일은 변경하지 않습니다. 원본 엑셀은 읽기만 하고, 정리 결과는 새 Excel 파일로 다운로드합니다. 쿠팡 입고 작업·바코드 라벨·서버 저장 데이터에도 영향을 주지 않습니다.
2. 선적 리스트 보관함 · 다른 페이지를 갔다 와도 이 PC에 작업이 남습니다
원본 파일과 센터의 팔레트/밀크런 선택 상태를 함께 보관합니다. 같은 PC·같은 브라우저에서는 페이지를 닫거나 다른 메뉴로 이동해도 자동 복구됩니다.
쿠팡 입고 작업으로 보내기를 누르면 현재 정리본으로 새 선적 작업을 만듭니다. 이미 진행 중인 다른 쿠팡 선적 작업은 수정하거나 덮어쓰지 않습니다.

파일을 불러오면 팔레트 센터와 밀크런 센터를 선택하는 창이 먼저 열립니다.

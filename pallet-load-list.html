쿠팡 팔레트 적재리스트 PDF / PowerPoint 생성

선적/팩킹 엑셀에서 밀크런 센터를 선택하고 쿠팡 PO를 올리면 팔레트별 적재리스트를 자동 생성합니다.

1 선적/팩킹 완료 엑셀

밀크런이 들어있는 선적 엑셀을 여기에 끌어놓으세요예: 코리아원 ○월○일 선적건.xlsx
선택된 파일 없음
만들 센터의 밀크런을 선택하세요

2 쿠팡 발주서(PO_FOR_CONFIRM)

선택한 센터의 쿠팡 발주서 Excel을 올려주세요센터 + 상품번호 + 확정수량을 기준으로 발주번호를 자동 배정합니다.
센터를 먼저 선택해 주세요

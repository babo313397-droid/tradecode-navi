바코드 라벨 생성기

라벨 크기를 mm로 입력하면 같은 비율로 미리보기하고, PDF도 입력한 실제 크기로 저장합니다.

라벨 내용 입력

글자 / 바코드 크기
공용 라벨 보관함
※ 공용 라벨은 다른 컴퓨터에서도 같은 목록을 사용합니다. Supabase 연결 시 재배포 후에도 영구 보관됩니다. 개인 기본설정(수입원·글자크기 등)은 현재 브라우저에 따로 기억됩니다.
파일 출력
· 바로 인쇄를 누르면 브라우저 인쇄창이 바로 열립니다. 배율은 실제 크기 / 100%를 권장합니다.
· 엑셀 다운로드에는 입력한 제품정보와 현재 라벨 미리보기 이미지가 함께 저장됩니다.
· CODE128은 영문과 숫자를 함께 사용할 수 있습니다.
· GS1/EAN 등 공식 유통 상품바코드가 필요한 경우 임의의 CODE128 번호와는 별도로 확인해야 합니다.

실시간 미리보기

감열프린터가 연결되지 않으면 QZ Tray 설치 후 다시 연결을 눌러주세요.
라벨 크기: 50 × 60 mm

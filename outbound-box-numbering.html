🔢 출고박스 자동넘버링

선적/팩킹 완료 Excel 한 개만 올리면 각 시트의 박스번호 옆 출고박스번호를 1번부터 시트 순서대로 자동 입력합니다.
기존 상품·박스번호·수량·수식·다른 작업값은 변경하지 않습니다.

✓ 박스번호 옆 열만 자동 입력
① 선적/팩킹 Excel 파일
자동넘버링 기준 · `박스번호`가 단일 번호면 출고박스번호도 단일 번호로 입력하고, `6~10`처럼 여러 박스 범위면 같은 개수만큼 `1~5`처럼 범위로 입력합니다. 이미 출고박스번호가 들어있는 셀은 절대 덮어쓰지 않고 그대로 유지하되, 해당 박스 개수는 전체 순번 계산에는 포함합니다.
파일을 선택하면 자동으로 분석합니다.
② 자동넘버링 결과
처리 시트0
새로 번호 매긴 박스0
기존 번호 유지 박스0
최종 순번0
시트순번 계산 구간새 번호 박스기존 번호 유지상태
※ 원본 파일 자체는 변경하지 않습니다. Excel 전체를 다시 저장하지 않고 필요한 출고박스번호 셀/병합만 수정하므로 원본의 수식·서식·도형·관계정보를 그대로 보존합니다.
